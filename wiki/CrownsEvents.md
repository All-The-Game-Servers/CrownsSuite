## 1.5.0 Season 1 Endfall

CrownsEvents `1.5.0` makes Endfall production-ready for Season 1 without CrownsMMO or CrownsTerrain.

- Runs in the vanilla End dimension.
- Keeps Nether Week archived and selectable.
- Requires staff activation so Endfall does not start accidentally on install.
- Lets staff run `/events admin activate end-opening`, `/events admin schedule end-opening <yyyy-MM-dd HH:mm>`, `/events admin start end-opening`, `/events admin end end-opening`, and `/events admin dryrun end-opening`.
- Controls the End opening lock through CrownsEvents when CrownsEconomy is installed.
- Tracks dragon ceremony, End entry, survey caches, chorus harvests, voidbound elites, relic turn-ins, milestones, rewards, and top collector rewards.
