# Installation

## Required

Server target: Paper/Minecraft `26.1.2` with Java `25`.

1. Install `CrownsAPI-0.1.3.jar`.
2. Install `CrownsMagic-0.2.0.jar` if you want magic.
3. Install `CrownsSwords-0.2.0.jar` if you want sword arts.
4. Host `CrownsSuite-ResourcePack-1.7.1.zip` through GitHub Releases or your preferred direct-download host.
5. Configure CrownsAPI resource-pack metadata with the pack URL and SHA1.
