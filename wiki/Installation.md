# Installation

## Required

1. Install `CrownsAPI-0.1.2.jar`.
2. Install `CrownsMagic-0.1.0.jar` if you want magic.
3. Install `CrownsSwords-0.1.0.jar` if you want sword arts.
4. Host `CrownsSuite-ResourcePack-1.7.0.zip` through GitHub Releases or your preferred direct-download host.
5. Configure CrownsAPI resource-pack metadata with the pack URL and SHA1.

## Current Downloads

The active artifacts are in the repository `downloads` folder:

- `CrownsAPI-0.1.2.jar`
- `CrownsMagic-0.1.0.jar`
- `CrownsSwords-0.1.0.jar`
- `CrownsSuite-ResourcePack-1.7.0.zip`
- `CrownsSuite-ResourcePack-1.7.0.sha1`

Do not install old 1.x suite jars from the deprecated branch unless you are intentionally testing legacy work.
