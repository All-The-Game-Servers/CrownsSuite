# CrownsEconomy

CrownsEconomy is the player trade and money loop for Crowns Suite.

## Main Systems

- Wallets and player payments
- Auction House
- Permanent branded stalls
- Jobs
- Server Demand Board
- Server Trader
- Gambling
- Player commissions
- Server contracts

## 1.2.0 Focus

- Themed Server Trader rotations
- Stall names, emblems, and descriptions
- Player buy orders through commissions
- Curated server contracts with limited slots

## Core Loop

Players earn money through gathering, jobs, auctions, stalls, and contracts. They spend it on market activity, trader rotations, stall upgrades, and prestige or utility purchases.
